# ProofCast 🔐

**Blockchain-Verified Announcements Platform**

Create timestamped, digitally signed announcements with cryptographic proof on Ethereum blockchain.

## 🚀 Features

- **🔒 Create Verifiable Announcements** - Notarize messages with one click
- **🖊️ Digital Signatures** - MetaMask-powered cryptographic signing
- **⛓️ Blockchain Witness** - Immutable records on Ethereum Sepolia
- **🌐 IPFS Storage** - Permanent, decentralized content storage
- **✅ Instant Verification** - Prove authenticity with cryptographic proof

## 🛠 Tech Stack

**Frontend:**
- React 18 + TypeScript + Vite
- CSS3 + Responsive Design

**Blockchain:**
- Ethereum Sepolia Testnet
- MetaMask Integration
- Ethers.js v6
- Aqua Protocol SDK

**Storage & Infrastructure:**
- IPFS + Pinata
- Environment Variables

## 🔧 How It Works

1. **Create**: Type message → IPFS upload → Digital signature → Blockchain witness
2. **Verify**: Paste content + proof → Cryptographic verification → Authenticity result
